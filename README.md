# 🧠 Psicologia do Conteúdo Viral — Skill pro Claude

> Uma skill pro Claude que aplica 6 princípios de psicologia humana pra criar **hooks** e **roteiros de vídeo** que viralizam. Baseada em frameworks que já geraram **+3 bilhões de views** em marcas "chatas" (ramen, software, telecom, restaurantes).

---

## 🎯 O que essa skill faz

Toda decisão de assistir, terminar ou compartilhar um vídeo acontece em **filtros mentais inconscientes** dos primeiros 2 segundos. Essa skill ensina o Claude a traduzir esses filtros em regras práticas — então toda vez que você pedir um hook, roteiro ou ideia de vídeo, o Claude já aplica automaticamente:

1. **Format Steal** — Familiaridade vence originalidade
2. **Curiosity Trap** — Nunca começar pelo produto
3. **Identidade > Produto** — Falar de quem o espectador SE TORNA, não de features
4. **Credenciais como atalho cognitivo** — Autoridade nos primeiros 2 segundos
5. **Shareability** — As pessoas compartilham o que as faz parecer bem
6. **Estrutura narrativa** — Hook → Problema → História → Payoff

## 📦 Como instalar no Claude (passo a passo)

A skill funciona no **Claude Desktop** (com Cowork mode) e no **Claude Code**.

### Passo 1 — Baixa o arquivo `SKILL.md`

Clica em `SKILL.md` aqui no repo → botão **"Download raw file"** (canto superior direito do arquivo) → salva no teu computador.

Ou, no terminal:
```bash
curl -O https://raw.githubusercontent.com/bdoisss-prog/psicologia-conteudo-viral/main/SKILL.md
```

### Passo 2 — Abre o Claude Desktop

Se ainda não tem, baixa em https://claude.ai/download

### Passo 3 — Vai em Configurações → Customizar Habilidades

No Claude Desktop:
1. Clica na tua foto (canto superior direito)
2. **Configurações** → **Customizar habilidades**
3. Clica no botão **"+"** → **"Fazer upload de uma habilidade"**

### Passo 4 — Arrasta o arquivo `SKILL.md`

Solta o arquivo `SKILL.md` que você baixou na área de upload.

✅ Pronto. A skill já está instalada e disponível em qualquer conversa nova.

## 🚀 Como usar

Depois de instalada, é só pedir naturalmente. A skill ativa sozinha quando o Claude detectar pedidos como:

```
"me dá um hook pra esse vídeo sobre [tema]"
"cria um roteiro de 30s pra Reels sobre [produto]"
"analisa esse roteiro e me fala o que tá errado"
"como eu viralizo no TikTok falando sobre [nicho]?"
```

### Exemplo de uso real

**Você pede:**
> "Cria um roteiro de 30s pra Reels sobre meu curso de inglês"

**O Claude responde aplicando a skill:**
- Sobe a escada de identidade (não é "curso de inglês", é "pessoa que se sente livre pra viajar e trabalhar globalmente")
- Identifica um formato viral comprovado pra usar de base
- Escreve o hook com curiosity gap + credencial nos primeiros 2 segundos
- Estrutura o roteiro em Hook → Problema → História → Payoff
- Adiciona notas de execução visual (cortes, legendas, cenário)
- Termina com o teste de shareability

## 🧪 3 Workflows da skill

A skill tem **3 modos de operação** que ativam automaticamente conforme o que você pedir:

| Workflow | Quando ativa | O que entrega |
|---|---|---|
| **A — Hook do zero** | Você pediu "hook", "abertura", "gancho", "primeiros 2 segundos" | 2-3 formatos virais comprovados, cada um com 3 variações de hook |
| **B — Roteiro completo** | Você pediu "roteiro", "script", "vídeo completo sobre X" | Roteiro estruturado em 4 partes (Hook → Problema → História → Payoff) com notas de execução |
| **C — Análise/crítica** | Você colou um roteiro existente pra analisar/melhorar | Diagnóstico nota 0-10 em cada princípio + reescrita das partes problemáticas |
